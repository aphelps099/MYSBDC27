Every /api/… path below is a proposed application interface. No live request is sent by this page.

Identity stays on the server.

Resolve the MySBDC session to the Neoserra client ID server-side. Never trust a client-supplied ID to grant access. Advisors are limited to caseload, directors to their center, and Lead Center to authorized network access.

A URL is not a session.

AWS presigned URLs are bearer tokens. For the reference’s session-bound download requirement, use an authenticated download broker or proxy that rechecks access on each request; a signed S3 URL alone does not enforce the MySBDC login session.

AWS documentation

Delivery must survive retries.

Use idempotency keys for writes, event IDs for deduplication, signed integration events, and reconciliation if a callback is delayed. Preserve drafts and show a retryable error instead of pretending a submission succeeded.

Documents have a lifecycle.

Check request access before upload, validate file type/size and content, quarantine pending scans, and mark received only after storage and metadata checks pass. Keep original and returned versions in AWS; Workspace holds working copies.

Before implementation

Decisions for the teams.

MySBDC + Emumba

Confirm the suggested JavaScript embed, short-lived token exchange, browser isolation, file limits, scan/retry states, and authenticated download delivery.

Neoserra + intake

Confirm field mapping, duplicate matching, consent capture, record creation rules, routing ownership, and the response-time target.

Training + outcomes

Confirm the registration system, seat limits, waitlists, attendance sync, milestone evidence and review, and final reporting ownership.
