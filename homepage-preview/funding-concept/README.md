# Funding concept — November 24, 2026

Separate local design study of `Funding.dc.html`, following the current page concepts. Preview: http://127.0.0.1:8784/homepage-preview/funding-concept/ . Original prototype, existing concepts, shared CSS, WordPress theme and saved content are unchanged. No publishing.

## Design and behavior

Navy Funding title and opening; original oversized dollar/banknote illustration bridging into cream; two reported results; six native funding-option disclosures; pool preparation section; real Yarrow Goods example; five FAQ disclosures; compact lender/partner invitation; single primary closing advising action. Proxima Nova and established cream/navy/pool/red palette. No eyebrows, decorative numbering, generic boxed cards or repeated bottom signup pitches. The lower photograph has a red bottom rule only, with no blue offset backing. Shared MySBDC/language controls and complete footer retained.

`assets/business-capital.svg` and `assets/funding-plan.svg` are original vector artwork created for this study. All graphic geometry, including dollar symbols, is editable SVG; no image generation or external illustration license needed. Decorative images have empty alt text and are hidden from assistive technology. Existing business photograph remains hosted on NorCal SBDC.

Funding disclosures and FAQ work without JavaScript. JS only handles shared scroll-header and language dismissal. Advising links use the existing Finance Center intake at `https://www.norcalsbdc.org/join/?program=FC`. Fundica and Tech Futures Group links open actual informational destinations. Partner contact uses the existing network inbox with a Finance Center subject; no dedicated partner integration invented. No form submissions or emails were sent. MySBDC remains the existing sibling-concept destination; language menu honestly shows English with future-language notice.
