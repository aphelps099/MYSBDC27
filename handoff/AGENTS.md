# MySBDC dashboard guidance

Read [DESIGN.md](DESIGN.md) before designing or changing pages in this directory. It records the
user-approved design philosophy and is the visual standard for future dashboard work.

- Work from `handoff/`; the refined Home page is the reference for typography, navy surfaces,
  spacing, and restrained symbols.
- Preserve the softened milestone icons and the removal of decorative “01 / 02 / 03 / 04” labels.
- Follow the dashboard guidance when public marketing-page rules in the root `CLAUDE.md` differ.
- Follow [README.md](README.md) for source files, rebuilding, and interaction requirements.
